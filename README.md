## 2. Website Page Map
### Part 1: Assignment 1 (HTML5 & CSS3 Fundamentals)
1. **Home (`index.html` + `home.css`):** Studio introduction practicing element, class, and ID selectors, typography, borders, and background colors.
2. **Media & Press Kit (`media.html` + `media.css`):** Flagship game trailer, OST audio sample, feature lists, and PC System Requirements table practicing the CSS Box Model, `background-image`, `display`, `position`, `float`, and `overflow`.
3. **Job Application (`register.html` + `register.css`):** Technical recruitment form using all 14 HTML5 input types and 9 validation attributes, styled with attribute selectors, combinators, pseudo-classes, and pseudo-elements.

### Part 2: Assignment 2 (Planned — Flexbox, Grid, Responsive & DOM)
4. **Games Showcase (`services.html` + `services.css`):** Flexbox game cards with hover transforms and transitions.
5. **Dev Logs (`portfolio.html` + `portfolio.css`):** CSS Grid concept art gallery with `@keyframes` animation and media queries.
6. **About Us & Contact (`contact.html` + `contact.css` + `contact.js`):** Responsive Flexbox/Grid hybrid page with a JavaScript DOM script.
